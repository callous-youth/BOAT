# Security Policy

## Supported Versions

BOAT currently provides security updates for the latest released version.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues or Discussions.

Report security concerns privately by emailing **liuyaohua.918@gmail.com**.

Please include, where possible:

- The affected BOAT version
- A description of the issue
- Steps to reproduce it
- The potential impact

The maintainers will review the report and coordinate any necessary fix and disclosure.
